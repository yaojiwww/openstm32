# 实训 1：参数配置与本地交互基础设施

## 需求拆解

输入检测 → 判断单击/长按 → 修改参数 → 校验并持久化 → LED/蜂鸣器反馈。参数不是几个散落的全局变量，而是一个 `AppConfig` 结构体。代码见 `config.*`、`button.*` 和 `Examples/lab1.c`。

## 数据设计

`sample_rate_hz`、`alarm_threshold_mv`、`filter_window` 被一起保存。外层再加 magic 和 checksum：启动时只有三者都合理才接受 EEPROM 内容，否则恢复默认值。写完还会读回比较，避免“函数返回了，但数据没真正写好”。

## 消抖与交互

主循环每 1–5 ms 调用一次 `button_update`。原始电平连续稳定 20 ms 才改变状态；按住 800 ms 产生长按事件。本例单击按 10/100/1000 Hz 循环，长按恢复默认参数。

AT24Cxx EEPROM 地址、页大小和地址字节数可能不同。第一版参考实现以 `0x50`、16 位存储地址写一个小结构；使用前核对你板上的 EEPROM 型号。不要每次主循环都写 EEPROM，它有写入寿命限制。

## 示波器观察按键抖动

探头接 KEY 信号，地夹接开发板 GND，先用 1 ms/div 左右观察。单次触发捕捉按下边沿，保存原始毛刺；再额外用一个调试 GPIO 表示“软件确认按下”，对比它在稳定 20 ms 后才变化。
