# 实训 3：手动采样模式

## 只改触发，不重写采集

自动采样由定时器触发，手动采样由按键事件触发；后面的 ADC、滤波、毫伏换算都复用 `Sampler`。代码见 `Examples/lab3.c`。

中断只把 `trigger_pending` 置位。主循环看到标志后先把 `sampling` 设为 true，再采样并打印：

```text
sample=2038, 1642 mV
```

完成后才允许下一次触发。这叫“忙保护”。更高速的系统可把单一标志改成事件队列，但本章先建立互斥意识。

## 串口验证

USART1 设置 115200、8 数据位、无校验、1 停止位。调试助手选择正确串口和相同参数。每按一次记录：按键边沿时间、串口文本出现时间和值。若乱码，优先核对波特率和时钟；若漏触发，查看消抖和忙标志。
