# 实训 2：自动采样模式

## 采集链路

TIM2 周期到 → 中断只设置 `sample_due` → 主循环读取 ADC → 移动平均 → 换算毫伏 → 追加 CSV → 检查错误。代码见 `sampler.*`、`filter.*`、`storage.*` 和 `Examples/lab2.c`。

CSV 每行格式为：

```text
timestamp_ms,raw,filtered,millivolts
1250,2051,2048,1650
```

这种格式方便直接用表格软件画图。产品化时可换二进制格式节省空间，但学习阶段先保证可观察。

## CubeMX 配置重点

- ADC1 选 12 bit、单通道，输入不能超过参考电压。
- TIM2 更新中断只发采样事件。不要在定时器中断里等待 ADC 或写 SD 卡。
- 开启 FATFS，并接入与你板卡一致的 SPI SD 底层驱动。SD 初始化通常先低速，成功后再提速。
- `filter_window` 越大越平滑，但响应越慢。

## 两种实测

1. 万用表测 ADC 输入电压，与日志中的 `millivolts` 对比。换算使用 `filtered × 3300 / 4095`；真实 VDDA 不是正好 3.300 V 时会产生系统误差。
2. 逻辑分析仪接 SCK/MOSI/MISO/CS，共地。先确认有时钟和片选，再看是否有响应；不要一开始就试图逐位理解全部协议。

采样率升高后，瓶颈常是阻塞式 SD 写入而不是 ADC。本章先观察，实训 8 再用 DMA 与缓冲解耦。
