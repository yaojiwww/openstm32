# 实训 4：数据回放模式

## 读取路径

挂载 SD 卡 → 打开 `samples.csv` → 逐行读取 → UART 回传 → 检查读错误 → 关闭文件。代码见 `storage_replay` 和 `Examples/lab4.c`。

读取与写入都有挂载、打开、传输、关闭，但并不完全对称：写入要考虑空间、掉电和 `f_sync`；读取要考虑文件不存在、文件指针和损坏内容。逐行缓冲区固定为 96 字节，因此本项目生成的单行必须小于此长度。

串口输出使用明确边界：

```text
BEGIN REPLAY
1250,2051,2048,1650
...
END REPLAY
```

后续上位机可据此区分实时状态和回放内容。

## 调试顺序

先在电脑确认 SD 卡里确实有文件，再看串口是否出现 `BEGIN`，最后用逻辑分析仪检查 SPI 的 CS、SCK、MISO。若有命令但 MISO 一直不变，检查供电、卡座和模式；若底层读到了数据但串口没有输出，断点检查 `f_gets` 与回调返回值。
