# 环境搭建速查表

目标：半天内完成“创建工程 → 编译 → ST-LINK 烧录 → LED 有反应”。不使用 Docker 或其他容器。

## 准备

- 野火 STM32F407ZGT6 开发板、配套 USB 线、ST-LINK。
- Windows、macOS 或 Linux 电脑。
- 从 ST 官网安装 STM32CubeIDE（安装包已包含 CubeMX、编译器和调试器）。首次启动时选择一个纯英文、无空格的 workspace 路径。
- 安装 ST-LINK 驱动；Linux 还需安装 ST 官方 udev 规则。macOS 通常无需单独驱动。
- 准备串口调试助手：Windows 可用野火多功能调试助手，macOS/Linux 可用 CoolTerm、Serial 或 `screen`。

> 安装链接和界面可能随版本变化，请从 ST 官方 STM32CubeIDE 产品页下载当前版本，不要从不明网盘取安装包。

## 创建工程模板

1. 打开 STM32CubeIDE，选择 **File → New → STM32 Project**。
2. 在 MCU/MPU Selector 中搜索 `STM32F407ZGT6`。如果你手中的板卡型号不同，按芯片丝印选择真实型号。
3. Project Name 填 `openstm32-workstation`，Targeted Language 选 C，Binary Type 选 Executable。
4. 在 CubeMX 页面配置时钟。F407 常见外部晶振为 8 MHz，但必须以开发板原理图为准；先让 Clock Configuration 自动解冲突。
5. 给 LED、KEY、SD_CS 等管脚设置 **User Label**。业务代码只认这些名字。
6. Project Manager → Code Generator 勾选“为每个外设生成独立 `.c/.h` 文件”，然后生成代码。
7. 将本仓库 `Firmware/App`、`Firmware/Port` 加入工程 Include Path 和 Source Location，具体见 `Firmware/README.md`。

## 推荐外设配置

| 功能 | CubeMX 外设 | 建议配置 |
|---|---|---|
| 调试串口 | USART1 | 115200, 8-N-1 |
| LED/蜂鸣器 | GPIO Output | 初始为关闭电平 |
| 按键 | GPIO EXTI | 依原理图选择上下拉和边沿 |
| ADC | ADC1 + DMA | 12 bit，先单通道 |
| 定时触发 | TIM2 | 更新中断，频率由参数决定 |
| SD 卡 | SPI1 + GPIO CS | 低速初始化，后切高速 |
| EEPROM | I2C1 | 先确认芯片是 AT24Cxx 还是片内 Flash 模拟 |
| 测试波形 | DAC1 + TIM6 + DMA | 实训 8 再开启 |
| 看门狗 | IWDG | 实训 5 再开启，调试初期先关闭 |

## 导入与编译

已有 CubeIDE 工程时，选择 **File → Import → Existing Projects into Workspace**。点击锤子图标编译；Console 最后显示 `0 errors` 才继续。若提示找不到头文件，检查 `Firmware/App`、`Firmware/Port` 和 `Core/Inc` 是否都在 Include Path。

## ST-LINK 连接检查

- 开发板供电正常，ST-LINK 的 SWDIO、SWCLK、GND、3.3V 参考电压连接正确。
- CubeIDE 点击虫子图标，选择 STM32 C/C++ Application。
- 若出现 `No ST-LINK detected`，先换数据线/USB 口，再检查驱动。
- 若出现 `Target not found`，检查供电、共地、SWD 接线，并尝试“Connect under reset”。

## 够用 C 语法清单

```c
uint32_t sample_rate = 100;             // 变量
if (sample_rate > 1000) { /* ... */ }   // 判断
for (uint8_t i = 0; i < 8; ++i) { }     // 循环
uint16_t read_adc(void);                 // 函数声明
void set_rate(uint32_t *rate);           // 指针：把变量地址交给函数
typedef struct {                         // 结构体：把一组数据打包
    uint32_t sample_rate_hz;
    uint16_t alarm_threshold;
} AppConfig;
```

现在只需能认出这些写法。后面遇到数组、枚举、函数指针时再结合实际代码学习。
