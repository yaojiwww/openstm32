# 实训 7：上位机通讯协议

## 帧格式

协议采用二进制帧，代码见 `protocol.*` 和 `Examples/lab7.c`。

| 字段 | 字节数 | 说明 |
|---|---:|---|
| SOF | 2 | 固定 `AA 55` |
| LENGTH | 1 | PAYLOAD 长度，0–16 |
| COMMAND | 1 | 指令码 |
| PAYLOAD | N | 参数，小端序 |
| CRC8 | 1 | 对 LENGTH、COMMAND、PAYLOAD 计算，poly `0x07` |

指令：`01` 启动、`02` 停止、`03` 查询、`04` 设置采样率（4 字节）、`05` 设置模式（1 字节）、`06` 回放。解析器逐字节推进，可以处理粘包、拆包和帧头前噪声，而不是假设一次 UART 回调恰好收到一整帧。

应答命令码为请求命令码 OR `0x80`。应答载荷第一个字节是错误码：0 成功、1 长度错误、2 参数越界、3 未知命令。查询成功时后续返回模式、运行标志和 4 字节采样率。

例如设置 100 Hz 的请求体是 `04 64 00 00 00`，完整帧可用 `protocol_encode` 生成，避免手算 CRC。第一版已经实现统一应答和错误码；下一版可补充请求序号与帧接收超时。
