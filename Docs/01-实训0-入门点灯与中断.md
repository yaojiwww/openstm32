# 实训 0：入门点灯与中断

## 目标与拆解

最终现象是“上电 LED 亮，按键后 LED 翻转”。先拆成三件事：GPIO 输出写电平、GPIO 输入读电平、按键边沿产生中断。代码见 `Firmware/Examples/lab0.c` 和 `Firmware/Port/board_port_stm32f407_hal.c`。

## CubeMX 配置

1. 按原理图把板载 LED 引脚设为 GPIO_Output，用户标签 `LED`，低速推挽输出。
2. 按键引脚设为 GPIO_EXTI，用户标签 `KEY`。上拉/下拉和触发边沿必须按原理图决定；参考代码按低电平按下处理。
3. NVIC 中启用对应 EXTI 中断。生成工程并编译。

在 `main.c` 的初始化区调用 `lab0_init()`。在 CubeMX 预留的用户代码区加入：

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    if (GPIO_Pin == KEY_Pin) {
        lab0_on_key_interrupt();
    }
}
```

## 第一次完整编译、烧录、运行

1. **编译**：点击锤子。编译器把 C 代码变成 MCU 可执行的 `.elf`，必须看到 `0 errors`。
2. **烧录**：连接 ST-LINK，点击 Run。IDE 把程序写入芯片 Flash；下载进度到 100%。
3. **运行**：复位 MCU。上电后执行 `HAL_Init`、时钟和 GPIO 初始化，然后进入 `lab0_init` 与主循环。
4. 若 LED 逻辑相反，只改 `board_led_set` 的有效电平，不要在每处业务代码里都取反。

## 用万用表验证

黑表笔接 GND，红表笔测 LED GPIO 端（不要直接跨接电流档）。记录 LED 开/关时电压。若代码写高但实测接近 0 V，优先核对有效电平与测量点。
